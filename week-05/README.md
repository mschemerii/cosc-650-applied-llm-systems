# Week 5

## The Chunking Decision

This directory contains the Week 5 discussion experiment and validation artifacts.

- `discussion-chunking-decision-canvas.txt` — Canvas-ready 250–350 word discussion post.
- `discussion-chunking-decision.md` — Markdown copy of the discussion.
- `week5_chunking_decision.ipynb` — Python notebook used to validate the three chunking strategies and retrieval results.
- `week5_chunking_decision.html` — exported HTML submission artifact.

The experiment uses the `llama.cpp` HTTP Server README pinned to commit `217f81c266a7b7c986ee3d2c58e1cccee05a0744`.

**Submission format:** submit only `week5_chunking_decision.html` for the notebook assignment. The notebook remains in the repository as the reproducible validation source.
