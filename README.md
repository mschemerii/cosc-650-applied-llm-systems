# COSC 650: Applied LLM Systems

This repository contains my coursework, experiments, and projects for COSC 650: Applied LLM Systems at Maryville University.

## Course Context

COSC 650 is an eight-week graduate course focused on the design and implementation of applied large language model systems. The course covers topics including tokenization, transformer architecture, prompt engineering, function calling, retrieval-augmented generation, fine-tuning, and evaluation.

My goal is to develop a deeper understanding of what happens beneath LLM frameworks so I can design systems intentionally rather than simply connect libraries. In particular, I want to be able to build and evaluate LLM applications that use tools, retrieval, structured outputs, and local models while understanding why each component works.

## Repository Organization
